# proteanTecs

> proteanTecs is a deep data analytics company for advanced electronics, headquartered in
> Haifa, Israel. It embeds on-chip monitoring Agents into semiconductor designs and pairs
> them with cloud and edge machine-learning applications that report the health,
> performance, reliability and quality of chips and systems from design, through production
> test, into field operation.

## API status — read this first

proteanTecs publishes **no public developer program**: no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK on any package registry, no MCP
server, and no A2A agent card. Its chip-production solution page states that "the solution
provides APIs and data connectors for seamless integration with ATEs and analytics tools",
but that surface is delivered to contracted customers. The only API-bearing host,
https://support.proteantecs.com/, answers anonymous callers with
`401 {"status":401,"message":"User is missing, you are probably not logged in"}` and
returns a Cloudflare 403 interstitial on every deeper path.

Do not attempt to construct a proteanTecs API call from this file. There is no public
contract to call.

## Optional

- The proteanTecs GitHub organization (https://github.com/proteantecs) holds 10 public
  repositories. Nine are forks of third-party infrastructure projects (argo-cd, mlrun,
  mlrun-ui, flink-on-k8s-operator, registry, k8s-pod-restart-info-collector,
  pr-size-labeler, shell-checker, lintly-flake8-github-action). The one non-fork,
  `proteantecs/ts-api`, is a Java project containing JAXB bindings generated from
  Tableau's REST API schema (`src/main/resources/ts-api_3_3.xsd`, package
  `com.tableau.generated.api`). It describes **Tableau's** API, not proteanTecs', and is
  therefore not a proteanTecs contract.
